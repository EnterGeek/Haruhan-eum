## 1. 목적

이 문서는 Work 01 색상 덱·스와이프 세션 프로토타입을 실제 브라우저에서 조작해 확인한 수동 테스트 결과를 보존한다.

검증의 중심은 색상 취향이나 심리 결과가 아니라 다음 네 가지다.

1. 12장의 제시 순서가 유지되는가

## 5. 데이터 무결성 확인

대표 세션 전체에서 다음 조건을 확인했다.

- `deck.cards.length === 12`
- `decisions.length === 12`
- `presentedOrder`가 1부터 12까지 순차적임
- 모든 `cardId`가 유일함
- 같은 순서의 카드와 결정이 동일한 ID·HEX·OKLCH 좌표를 가짐
- 각 결정의 `deckVersion`과 `deckSeed`가 덱 기준값과 일치함
- 이벤트 `sequence`가 1부터 누락 없이 증가함
- 마지막 결정과 `session_completed`의 시각이 일치함
- 완료 이벤트가 정확히 한 번 존재함
- 되돌려 취소된 방향이 최종 `decisions`에 남지 않음
