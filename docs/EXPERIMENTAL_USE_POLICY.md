# Experimental Use Policy

## 사용자 경험 원칙

사용자는 색을 기억하거나 색–음 대응을 맞힐 필요가 없습니다. 세션은 가볍고 낮은 인지 부담으로 끝나야 합니다.

```text
오늘을 잠깐 떠올림
→ 마음이 가는 방향으로 색에 반응
→ 짧은 멜로디 생성
```

## 비진단 원칙

색 선택은 여러 원인의 영향을 받는 약한 신호입니다. 따라서 다음 표현을 사용하지 않습니다.

- "현재 우울도"
- "불안 상태"
- "성격 유형"
- "정신건강 위험"
- 특정 색 하나를 근거로 한 감정 단정

내부 모델이 생성용 잠재 벡터를 계산하더라도, 이는 사용자의 심리적 진실이 아니라 음악 파라미터를 선택하기 위한 불확실한 중간 표현입니다.

## 사용자 고지

제품에서 최소한 다음 의미가 전달되어야 합니다.

> 색 선택은 오늘의 멜로디를 구성하는 데 사용되며, 감정이나 성격을 진단하지 않습니다.

기술적 세부 설명은 선택적으로 제공할 수 있지만, 진단이 아니라는 경계는 숨기지 않습니다.

## 연구 원칙

- 매핑 가설과 제품 결정을 구분합니다.
- 조건을 동시에 여러 개 바꾸지 않습니다.
- blind·순서 무작위화·모르겠다 응답을 허용합니다.
- 실험 결과에는 알고리즘·fixture·commit version을 기록합니다.
- 단일 사용자 또는 소규모 결과를 보편적 심리 법칙으로 확대하지 않습니다.
